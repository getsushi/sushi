Where this extension should find the app.

Sushi filled these in when it generated the extension. You only need to change them if the app reported a different port afterwards — Settings → Files in Sushi shows the current one.

The token is what stops any page you happen to visit from telling Sushi to fill a form. Treat it like a password: it belongs to this machine, and if it gets out, press Issue a new token in Sushi and generate the extension again.
