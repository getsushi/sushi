# Changelog

All notable changes to Sushi are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Contributing guide, code of conduct, security policy, and issue and pull
  request templates.
- Licence files for the bundled Bricolage Grotesque and Hanken Grotesk fonts.

### Fixed

- README links now point to the `getsushi/sushi` repository.

## [0.1.0] - 2026-11-19

First public release.

### Added

- CV reading from PDF, DOCX and TXT, with a profile you can correct.
- Job discovery from 13 ATS platforms and eight job-feed sites, with match
  scores and reasons.
- Browser form filling, Insane Mode with a daily limit, and review before
  submit.
- Answer memory that learns from your corrections.
- Cover letters, resume builder, application tracking with CSV export, and an
  assistant panel.
- Support for Claude Code, Groq, Gemini, OpenAI, Anthropic and Ollama models.
- Released under the MIT License.
